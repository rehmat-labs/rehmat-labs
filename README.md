- **Code-drawn video:** Remotion pipelines that turn scripts into finished videos, with stick-figure animation, explainers and subtitles drawn entirely in code
- **Business ERPs:** finance, inventory and factory management systems for real companies
- **WhatsApp automation:** bots and HTTP APIs that answer customers, send media and hand off to humans
